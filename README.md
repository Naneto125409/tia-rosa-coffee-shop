# ☕ CoffeeShop - Tia Rosa

Projeto desenvolvido com o objetivo de simular uma landing page para uma cafeteria fictícia, com foco na experiência do usuário, visual agradável, vitrine de produtos, carrinho de compras funcional, responsividade total para diferentes tamanhos de tela e botões flutuantes interativos.

## 📋 Objetivos do Projeto

- Criar uma landing page moderna e funcional para um coffee shop;
- Garantir acessibilidade e responsividade em múltiplos dispositivos;
- Utilizar técnicas de front-end e princípios de design UX/UI;
- Aplicar boas práticas de desenvolvimento com HTML, CSS, JavaScript e Bootstrap.

## 💻 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Bootstrap 5**
- **Figma** (protótipos)
- **Netlify** (hospedagem do projeto)

## 🧠 Suporte e Fontes Utilizadas

Durante o desenvolvimento, foram utilizados os seguintes recursos para estudo e apoio técnico:

- 🧠 **ChatGPT (OpenAI)** – apoio na lógica, responsividade e boas práticas;
- 📘 **MDN Web Docs** – documentação oficial de HTML, CSS e JS;
- 📚 **W3Schools** – exemplos e práticas rápidas de código;
- 🛠️ **Bootstrap** – framework para construção da interface;
- ✏️ **Figma** – para estruturação visual e prototipagem;
- 🌐 **Netlify** – hospedagem gratuita do projeto.

## 🧱 Estrutura do Projeto

Este projeto foi baseado no esqueleto desenvolvido no **ADS09**, onde foram aplicados conceitos de responsividade, componentes reutilizáveis e integração de design com Figma. A experiência anterior com ADS09 serviu como base para estruturar o HTML semântico, a organização dos componentes e o modelo adaptável para diferentes telas.
